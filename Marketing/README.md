# VisualLogic Marketing Resources

This folder contains public English-only materials for explaining VisualLogic, VL, VLC, and the DAG-centered AI software generation workflow.

## Core Message

VisualLogic is built for real software delivery, not code snippets. It combines:

- VL: an AI-native programming language designed for structured generation
- VLC: a free local IDE for building, inspecting, compiling, and previewing VL projects
- DAG workflows: explicit engineering harnesses for planning, generation, validation, repair, and delivery
- AI assistant control: a project-aware assistant that can operate the DAG and the project context together

The result is a practical system for turning product intent into full-stack applications. It is especially useful for teams that want AI to land inside real enterprise projects, where structure, repeatability, ownership, and review matter.

## Open Ecosystem

VisualLogic is designed as an open resource system. Builders can create, upload, share, and reuse:

- DAG flows
- components
- tools
- skills
- themes
- documents and generation context
- project templates and sample packs

Platform-provided resources are intended to be free for users to use. Community resources can be designed and uploaded by builders, teams, and component authors.
